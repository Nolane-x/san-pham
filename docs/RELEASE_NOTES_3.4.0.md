# Magic Capture Desktop 3.4.0

## Pin Power UX

- Place numbered Step markers directly on a live pin.
- Place bounded text notes directly on a live pin; clear session annotations without flattening the source image.
- Minimize pins, hide/restore a pin at the active screen edge, and lock/unlock pin movement/resizing.
- Remember the last visible pin position/size through the existing settings recovery-safe persistence path.
- Arrange all open pins into a bounded grid or snap them to work-area/neighbor edges.
- Pin an image directly from the Windows clipboard with a 128 MB encoded import ceiling and pixel-processing workload guard.
- Pin an arbitrary local image file after bounded decode/PNG normalization.

Crop-pin and persistent pin groups remain incomplete and are deliberately not counted as Done.
